# Icons do Projeto

Este diretório contém 10 ícones SVG simples que descrevem componentes do projeto OpenCode/documentação e engenharia de software.

- icons/icon-docs.svg: Documentação eanter texto
- icons/icon-code.svg: Snippet de código/engenharia
- icons/icon-uml.svg: UML e diagramação
- icons/icon-mermaid.svg: Diagramas Mermaid
- icons/icon-database.svg: Base de dados
- icons/icon-cloud.svg: Cloud e infra
- icons/icon-test.svg: Testes e validação
- icons/icon-automation.svg: Automação/CI
- icons/icon-user.svg: Utilizadores e papéis
- icons/icon-architecture.svg: Arquitetura de software

Uso: importar os SVGs como recursos em documentação, READMEs ou páginas de referência.
