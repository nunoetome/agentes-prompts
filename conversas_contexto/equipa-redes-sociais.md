# Contexto - Criação de Equipa de Agentes de Redes Sociais

## Data: 17 de Abril de 2026

## Tarefa
O utilizador pediu para criar um agente "gestora de redes sociais chefe" com uma equipa de subagentes especializados, cada um para uma rede social diferente.

## Ação Tomada
Criação de 7 agentes no total:

### 1. Agente Chefe
- **ficheiro**: `gestor-redes-sociais-chefe.md`
- **função**: Coordenador que lidera a equipa, distribui tarefas e sintetiza resultados dos especialistas

### 2. Subagentes Especialistas
| Agente | Ficheiro | Especialidade |
|--------|---------|---------------|
| @instagram | instagram.md | Visual content, Reels, Stories, engagement |
| @facebook | facebook.md | Pages, Groups, Ads, community |
| @linkedin | linkedin.md | Professional networking, B2B, thought leadership |
| @twitter | twitter.md | Real-time updates, Threads, viral content |
| @tiktok | tiktok.md | Short video, Trends, Gen Z audience |
| @youtube | youtube.md | Long-form video, Shorts, monetization |

## Estrutura Criada
```
agentes_open_code/
├── gestor-redes-sociais-chefe.md  (chef)
├── instagram.md                   (specialist)
├── facebook.md                    (specialist)
├── linkedin.md                    (specialist)
├── twitter.md                     (specialist)
├── tiktok.md                      (specialist)
└── youtube.md                     (specialist)
```

## Como Usar
O utilizador deve conversar com o @gestor-redes-sociais-chefe, que vai coordenar a equipa e distribuir tarefas pelos subagentes apropriados.
