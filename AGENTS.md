# AGENTS.md

This repository is a **collection of prompts and agent configurations**, not a code project. There are no build scripts, tests, or CI/CD pipelines.

## Structure

- `agentes_open_code/` - Subagent prompt definitions for OpenCode sessions
  - `documentacao.md` - Documentation engineer prompt
  - `setup-projeto.md` - Project setup assistant prompt
  - `git-commits.md` - Git commit message specialist (PT-PT + EN-UK)
- `Prompts e bots/` - Miscellaneous prompts and bots
- `conversas_contexto/` - Saved conversation contexts
- `icons/` - Icon assets

## Working Here

- **No build commands** - This repo contains only Markdown files
- **No tests** - Nothing to run
- **Git commits** - Follow the format in `agentes_open_code/git-commits.md` (bilingual PT-PT/EN-UK)
- **Editing prompts** - The subagent definitions in `agentes_open_code/` define agent behavior for future sessions
